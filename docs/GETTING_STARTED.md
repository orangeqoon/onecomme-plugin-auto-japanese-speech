# はじめての導入ガイド

「日本語コメント音声切替」を、ダウンロードして使い始めるまでの手順です。プログラムの編集、Node.js、APIキー、GitHubアカウントは不要です。

> このガイドはWindows向けです。調査対象はわんコメ9.2.0-beta.0。ほかの版・OSは未確認です。日本語を含むコメント全体を日本語音声で読みます。コメントを翻訳する機能ではありません。

## 先に用意するもの

- 起動できるわんコメ。
- わんコメに登録した配信枠。
- わんコメから選べる日本語音声。英語も英語の発音で読みたい場合は、英語音声も必要です。

VOICEVOXなどの外部ソフトは、最初の導入には必要ありません。

![導入は、配布ZIPのダウンロード、展開、フォルダ配置、有効化、声の選択、コメント確認の順です](images/01-installation.png)

*図1：操作案内図です。わんコメ・GitHub・Windowsの画面写真ではありません。*

## 1. 配布ZIPをダウンロードする

[こちらのv1.2.0配布ページ](https://github.com/orangeqoon/onecomme-plugin-auto-japanese-speech/releases/tag/v1.2.0)を開きます。

下のほうにある **Assets**（配布ファイル一覧）から、次のファイルを選びます。折りたたまれていたらAssetsをクリックして開いてください。

**`auto-japanese-speech-1.2.0.zip`**

[配布ZIPを直接ダウンロードする](https://github.com/orangeqoon/onecomme-plugin-auto-japanese-speech/releases/download/v1.2.0/auto-japanese-speech-1.2.0.zip)

「Source code (zip)」「Source code (tar.gz)」は開発用です。初めて使うときは、上記の配布ZIPを選んでください。

## 2. ZIPを展開する

1. ダウンロードしたZIPを右クリックします。
2. **「すべて展開」**を選び、展開を実行します。
3. 展開先の中にある **`auto-japanese-speech` フォルダ**を見つけます。
4. そのフォルダを開き、`plugin.js` と `index.html` が入っていることを確認します。

ファイルの中身を編集する必要はありません。ZIPの中を開いて眺めるだけではなく、「すべて展開」してから次に進みます。

## 3. わんコメのプラグインフォルダへ入れる

1. わんコメを起動します。
2. わんコメの **右上メニュー →「プラグイン」** を開きます。
3. プラグイン画面の **「プラグインフォルダ」** を押します。
4. 開いた場所に、先ほどの **`auto-japanese-speech` フォルダごと**コピーします。

配置したフォルダを1回開くと、`plugin.js` が見える形にします。

![正しい配置はpluginsの直下にauto-japanese-speechを置き、その直下にplugin.jsとindex.htmlがある形です](images/02-folder-layout.png)

*図2：フォルダ構成の説明図です。実際のエクスプローラー画面ではありません。*

**よくある間違い**

- ZIPを展開せず、そのまま置く。
- `auto-japanese-speech` の中に、もう1つ `auto-japanese-speech` が入っている。
- フォルダの中身をわんコメ本体のインストール先へ入れる。

迷ったら、上の図の「正しい配置」と同じにしてください。[わんコメ公式の導入手順](https://onecomme.com/docs/feature/plugins/)も参照できます。

## 4. プラグインを有効にする

1. わんコメのプラグイン画面へ戻ります。
2. **「再読み込み」**を押します。
3. 一覧に出た **「日本語コメント音声切替」** を有効にします。
4. そのプラグインの **URLボタン／URLを開くアイコン**を押して、設定画面を開きます。

設定画面が開く間も、わんコメを起動しておいてください。設定画面はわんコメと通信して、枠名や音声一覧を読み込みます。

## 5. 枠ごとの声を選ぶ

まず、使いたい枠の **読み上げエンジンを「内蔵音声エンジン」** にします。わんコメの版によっては「標準」と表示されます。枠のエンジンは、その枠の **「… → 設定」** で確認できます。

![設定画面の見本。1はこの枠の設定、2は通常の声、3は日本語の声、4は設定を保存するボタンです](images/03-voice-settings.png)

*図3：実際のプラグイン画面を、架空の枠名・説明用の音声一覧で表示した見本です。番号を追加し、説明に不要な下部を省略しています。ご自身の画面では、登録した枠名とPCで使える音声が表示されます。*

図の番号の順に設定します。

1. **「この枠の設定」**を選びます。最初は「サイト設定を引き継ぐ」になっています。
2. **「通常の声」**を選びます。英語を英語の発音で読みたい枠では、`en-US` や `en-GB` などの英語音声を選びます。
3. 「日本語コメント」を **「日本語の声に切り替える」**にして、**「日本語の声」**を選びます。Haruka・Sayaka・Ayumiなど、表示される日本語音声から選べます。音声の種類はPCによって異なります。
4. **「設定を保存」**を押します。保存完了の表示を確認してください。

**まず試す設定例**

| 枠の使い方 | 通常の声 | 日本語コメント | 日本語の声 |
| --- | --- | --- | --- |
| 英語と日本語が来るTwitchの枠 | 利用可能な英語音声 | 日本語の声に切り替える | 利用可能な日本語音声 |
| 日本語中心のニコニコ・FC2などの枠 | 好きな日本語音声 | 同じ声を使う | 選択不要 |

「同じ声を使う」を選ぶと、日本語用の欄が灰色になります。通常の声を使う設定なので正常です。

「共通の日本語音声」は、日本語用の声を個別指定しなかった枠で使う音声です。最初は自動選択や初期値のままでもかまいません。

### 枠名・設定の引き継ぎについて

- 枠名は自動で読み込み、一覧を10秒ごとに更新します。枠名を手入力する必要はありません。
- 同じサイトの枠が複数あっても、別々に設定できます。
- 枠名だけ変えても設定は維持されます。枠を削除して作り直すと、新しい枠として扱います。
- 接続OFF・読み上げOFFの枠も一覧に出ます。この画面でON/OFFを変更することはありません。
- 「サイト設定を引き継ぐ」なら、下の「サイト別の共通設定」を使います。初めてなら、設定したい枠だけ「この枠の設定」にすれば十分です。
- 個別設定の「通常の声」が未指定なら、わんコメ本体の声を維持します。「日本語の声」が未指定なら、共通の日本語音声を使います。

## 6. 対象の枠で読み上げを確認する

1. わんコメ本体で、対象枠の読み上げをONにし、コメントを受け取れる状態にします。
2. 対象の配信サイトから、例えば `Hello!` → `こんにちは` → `Thank you!` とコメントします。
3. 「通常の声」「日本語の声」が指定どおりかを確認します。

通常のコメントテスターには枠の情報がないため、「その他・テスター」の設定が使われます。特定の枠の声を確かめるときは、**その枠で受け取るコメント**を使ってください。

日英が混ざった1つのコメントは、全体を日本語音声で読みます。文中の英語だけ別音声に分ける機能はありません。漢字だけの中国語も、日本語として判定されます。

## うまくいかないとき

| 困りごと | 確認すること |
| --- | --- |
| プラグイン一覧に出ない | 配布ZIPを展開したか。図2のように`plugin.js`を配置したか。「再読み込み」を押したか |
| 設定画面が開かない | わんコメが起動中か、プラグインを有効にしたか。プラグインのURLボタンから開いたか。APIのポートを独自に変更していないか |
| 枠が出ない・名前が古い | わんコメ本体にその枠が登録されているか。10秒待つか「再取得」を押す。「再取得」は未保存の選択を読み直すので、先に保存する |
| 音声の一覧が空 | わんコメの読み上げ設定を開いてから、プラグイン設定の「再取得」を押す。PCでその音声が使えるか確認する |
| 声を選ぶ欄が灰色 | 「この枠の設定」を選んだか。「同じ声を使う」の日本語欄だけなら正常。外部エンジンの枠では内蔵音声欄は無効になる |
| 保存したのに声が変わらない | 保存完了の表示を確認。同じサイトの別枠ではなく、設定した枠でコメントを受けているか。通常のテスターでは「その他」が使われる |
| 何も読み上げない | プラグインの前に、わんコメ本体で読み上げができるか確認。対象枠の読み上げON・音量・出力先を確認する |
| 日本語の声が見つからない | PC側で使える日本語音声が必要。表示される種類はPCごとに異なり、このプラグインが新しい音声をインストールすることはない |
| VOICEVOXの声が出てこない | VOICEVOXの声は内蔵音声の一覧には出ない。[外部TTSガイド](../EXTERNAL_TTS.md)を参照する |

改善しない場合は[Issues](https://github.com/orangeqoon/onecomme-plugin-auto-japanese-speech/issues)へ、OS・わんコメのバージョン・プラグインのバージョン・行った操作を記載してください。設定画面下の診断情報も参考になります。公開する前に枠名など、見せたくない情報がないか確認してください。

## すでに導入している人の更新手順

1. プラグイン設定で、編集中の設定を保存します。
2. わんコメのプラグイン画面で、このプラグインを無効にします。
3. 新しい配布ZIPを展開します。
4. 既存の`auto-japanese-speech`フォルダ内の **`plugin.js` と `index.html`** を新しいファイルで上書きします。
5. **`state.json`は削除しません。** 保存した設定が入っています。
6. わんコメで「再読み込み」→ 有効化し、設定が残っていることを確認します。

## VOICEVOXなども使いたい場合

初めは内蔵音声で動作確認してから、[外部TTSガイド](../EXTERNAL_TTS.md)へ進むと設定箇所を把握しやすくなります。外部TTSはわんコメ本体の「連携」で接続し、枠ごとの「… → 設定」で割り当てます。

このプラグインの一覧から外部話者を選ぶ機能や、同じ枠で「日本語だけVOICEVOX・英語は内蔵音声」に切り替える機能は、まだありません。

## 確認できている範囲

旧版の日本語自動切替はユーザーによる実機動作確認済みです。v1.2.0の枠別機能は模擬再生・設定画面のブラウザ操作・登録枠データの取得で検証済みですが、枠別の実音声は未確認です。わんコメの内部実装に依存する試験公開版のため、使用版を確認し、実際に使う前に読み上げを試してください。
