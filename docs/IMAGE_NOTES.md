## 再生成

画像用のHTMLとレンダラーは`tools/guide-images/`にある。画像を更新する開発者だけ、Node.js・Microsoft Edge・Playwrightが必要。利用者には不要。

リポジトリルートから:

```powershell
npm install --no-save --package-lock=false playwright
node tools/guide-images/render.cjs
```

PNGは`docs/images/`へ生成する。設定画面はローカルの仮URLへの通信を模擬応答で置き換え、実際のわんコメへはアクセスしない。生成後は全画像を開いて、文字の欠け・誤記・現行UIとの相違がないか目視する。

## 将来、わんコメ本体の実画面写真を追加する場合

現在の案内図で導入手順は説明できる。実画面も掲載したい場合は、次の3枚があると分かりやすい。

1. **わんコメ右上メニューを開いた画面**。「プラグイン」の項目が分かる範囲を切り出す。
2. **プラグイン一覧の画面**。「プラグインフォルダ」「再読み込み」「日本語コメント音声切替」の有効化・URLボタンが分かる状態にする。
3. **配置済みフォルダの画面**。`plugins/auto-japanese-speech/`の中に`plugin.js`と`index.html`があると分かるようにする。

使用したわんコメのバージョンを記録する。ユーザーフォルダ名、実際の配信URL・アカウント名、配信キー、ログイン情報、コメントなどが写っていれば、公開前に隠すか切り出す。本体のスクリーンショットはその旨を明記し、上の案内図やサンプル画面と区別する。
