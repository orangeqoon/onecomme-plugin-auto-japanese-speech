# 技術仕様と検証情報

[初心者向け導入ガイド](GETTING_STARTED.md) / [README](../README.md)

## 対象・制限

- 調査対象はWindows / OneComme 9.2.0-beta.0。他の版やOSは未確認。
- 日本語を含むコメント全体を日本語の内蔵音声で読む。文中の言語分割・翻訳はしない。漢字のみの中国語も日本語判定になる。
- 内蔵のWeb Speech音声が対象。外部エンジンはわんコメ本体で選択し、本プラグインの内蔵音声欄は無効になる。
- 同一枠内で「日本語はVOICEVOX・英語は内蔵音声」のようにエンジンを切り替える機能は未実装。
- 一般のコメントテスターや枠IDのない読み上げでは「その他」の設定を使う。

## 枠と音声の優先順位

- 枠の登録情報を`services`から取得し、枠IDで設定を保持する。名前・同一文章・直前に発話したサイトをキーにしない。
- 個別上書きONならその枠のルールを使用。OFFならサイトルールを使用。
- 個別設定の空の通常音声は本体の音声を維持。空の日本語音声は共通日本語音声へフォールバック。
- 日本語音声は、枠/サイトの日本語音声 → 共通日本語音声 → Sayaka → 利用可能な日本語音声の順で選択する。
- 通常音声が利用不可なら本体の音声を維持。利用不可の日本語音声は上記の順で代替する。
- 枠名変更は設定に影響しない。削除済みの枠のルールは保存データに残し、別のIDへ転用しない。
- 新しい枠・枠名・ON/OFFは10秒ごとに画面へ反映する。未保存の選択を維持する。

## 実装と権限

通常コメントの`filterSpeech`では変更した音声設定が再生側へ引き継がれない構造だったため、Electronのアプリ自身の`file:` rendererに限定してWeb Speech再生前のラッパーを設定する。アプリ本体のファイルは変更しない。公式に保証された音声切替APIではなく、わんコメ更新時の再検証が必要。

内部の`speechText`へサイト・枠IDのマーカーを付け、Web Speechへ渡す直前に取り除く。旧サイトマーカーも読み取り可能。他の文字列加工プラグインがマーカーを書き換える場合は互換性が失われる可能性がある。外部エンジンへはマーカーを付けない。

| 権限 | 用途 |
| --- | --- |
| `filter.speech` | 読み上げ文字列に枠識別情報を付与 |
| `services` | 登録枠の取得・変更検知・枠の外部エンジン判定 |
| `config` | 既定エンジン名の取得 |

`config`の診断出力は設定全体を含めない。枠の診断もID・名前・サイト種別・接続/読み上げON/OFF・エンジン名だけとし、配信URLやログイン情報は返さない。

このプラグインはコメントを外部へ送信せず、発話ログを保存しない。選択する音声エンジン自体の通信動作は、その音声に依存する。永続設定はわんコメ管理の`state.json`、発話カウンタはメモリ上に保持する。無効化時は元の読み上げ関数へ復元する。

## 開発・検証コマンド

利用者は実行不要。開発者はNode.js 22でリポジトリルートから実行する。実行・基本テストにnpm依存パッケージは不要。

```powershell
npm run check
npm test
```

導入画像の再生成方法は[画像について](IMAGE_NOTES.md)を参照。

## 確認状況

- 旧版の日本語自動切替は、ユーザーによる実機動作確認済み。
- v1.2.0は、同名別枠・同じ文章の連続再生・改名・並び替え・枠追加・削除後の設定保持・継承・日本語音声の優先順位を模擬テストで確認。
- 保存/再起動・保存失敗・不正設定・外部エンジン除外・診断からのURL除去・無効化時の復元も確認。
- ヘッドレスブラウザで保存・自動更新・改名・未保存選択保持・HTML文字列の安全な表示を確認。
- 実際の登録枠データ13件を使い、非接続枠を含めて候補APIへ全件含まれることを確認。公開するテスト・画像のデータは架空。
- 構文・パス・配置検査とGitHubのWindows自動テストに合格。
- **枠別の実音声・外部エンジンとの実音声は未確認。** ガイドの設定画面見本は実音声の動作証明ではない。
