置くのは、ZIPの中の「auto-japanese-speech」

わんコメの「プラグインフォルダ」を開いた場所で、次の形にします。

✓ 正しい配置

plugins/
└─ auto-japanese-speech/
   ├─ plugin.js
   ├─ index.html
   └─ README.md など

フォルダを1回開くと plugin.js が見える
状態ならOKです。READMEなどの説明書も
一緒に置いたままでかまいません。

× よくある置き間違い

plugins/
└─ auto-japanese-speech-1.3.0.zip

ZIPをそのまま置いても読み込まれません。

plugins/
└─ auto-japanese-speech/
   └─ auto-japanese-speech/
      └─ plugin.js

フォルダが二重になっている場合は、
plugin.js が入っている内側のフォルダを
plugins の直下へ配置します。

配置できたら、わんコメで 「再読み込み」→ 有効化。
更新するときは、先に無効化し、state.json は削除しないでください。

フォルダ構成の説明図です。実際のエクスプローラーの画面写真ではありません。
